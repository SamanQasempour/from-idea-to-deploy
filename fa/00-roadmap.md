# 00 — نقشه راه

## هدف
قبل از ترمینال، کل مسیر را ببینید.

## نتیجه موفق
بدانید فصل بعدی کدام است و «تمام‌شدن» هر مرحله یعنی چه.

## مسیر کلی

```text
ایده → دامنه → کد + گیت‌هاب → اجرای لوکال → VM
    → مودم/پورت (اگر خانگی/شرکت) → DNS/SSL کلودفلر
    → ریورس‌پراکسی (اگر چندسایت) → دیپلوی → سخت‌سازی → لانچ
```

## چک‌لیست مراحل

- [ ] MVP در یک صفحه نوشته شده
- [ ] دامنه خریده / NS آماده
- [ ] ریپو روی گیت‌هاب
- [ ] اپ لوکال بالا می‌آید
- [ ] VM با SSH در دسترس است
- [ ] HTTP/HTTPS به ماشین درست می‌رسد
- [ ] اپ با systemd (یا مشابه) اجرا می‌شود
- [ ] بکاپ + سیاست رمزها

## نکته
اگر تازه‌کارید، **شبکه** و **دیپلوی اپ** را یک‌روزه قاطی نکنید.
