# 06 — مودم و پورت‌فوروارد

## هدف
از اینترنت عمومی به VM داخلی پشت مودم برسید.

## واژه‌ها

| واژه | مثال |
|---|---|
| IP عمومی | `PUBLIC_IP` روی WAN |
| IP داخلی | `192.168.100.10` روی VM |
| پورت‌فوروارد | WAN `:80` → LAN `192.168.100.10:80` |

## منوی نمونه هواوی
**Forward Rules → Port Mapping Configuration**

## قواعد پیشنهادی

| نام | خارجی | میزبان داخلی | پورت داخلی | پروتکل |
|---|---|---|---|---|
| web-http | 80 | `192.168.100.10` | 80 | TCP |
| web-https | 443 | `192.168.100.10` | 443 | TCP |
| ssh-vm | 2202 | `192.168.100.10` | 22 | TCP |

## قانون تداخل
**هر پورت خارجی فقط به یک میزبان داخلی.**  
اگر 80/443 مال سایت دیگر است، ندزدید — روی همان سرور ریورس‌پراکسی بزنید (فصل 08).

## رزرو DHCP
MAC ماشین را به IP ثابت ببندید.

## تست با دیتای موبایل

```bash
curl -I http://PUBLIC_IP
```
