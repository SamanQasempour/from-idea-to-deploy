# 05b — انواع هاست و سرور

## هدف
جای درست برای اپ را انتخاب کنید.

## مقایسه

| نوع | کنترل | مناسب | درد |
|---|---|---|---|
| Shared | کم | سایت PHP استاتیک | برای Node + آپلود خصوصی بد |
| VPS / Cloud VM | زیاد | اکثر MVPهای SaaS | آپدیت OS با شماست |
| Dedicated | خیلی زیاد | بار سنگین | هزینه |
| Serverless | دیپلوی آسان | اپ بدون state | فایل محلی / جاب طولانی |
| سیستم خانگی پشت مودم | تقریباً رایگان | یادگیری / استیج | IP داینامیک، برق، NAT |

## حداقل برای Node + Postgres (سرانگشتی)

| منبع | حداقل | راحت |
|---|---|---|
| vCPU | 2 | 4 |
| RAM | 4 GB | 8 GB |
| Disk | 40 GB SSD | 80 GB+ |
| OS | Ubuntu 22.04+ | همان |

## ایران / خارج / VM شرکت
- VPS دیتاسنتر: IP عمومی روی خود ماشین → DNS ساده‌تر
- VM اداری/خانگی: IP عمومی روی مودم → پورت‌فوروارد (فصل 06)
- چند VM پشت یک IP → ریورس‌پراکسی (فصل 08)
