# 01b — خرید دامنه و انواع دامنه

## هدف
دامنه بخرید و به کلودفلر (یا DNS ثبت‌کننده) وصل کنید.

## پسوندهای رایج

| پسوند | توضیح |
|---|---|
| `.com` | پیش‌فرض جهانی |
| `.ir` | ایرنیک، قوانین داخلی |
| `.dev` / `.app` | معمولاً سخت‌گیرانه‌تر برای HTTPS |
| `.net` / `.org` | جایگزین خوب |

## از کجا بخرید
- **ایرنیک** برای `.ir`
- ثبت‌کننده‌های بین‌المللی
- جایی که بتوانید **Nameserver** را آزاد عوض کنید

## قدم‌ها

1. موجودی را جستجو کنید
2. ۱–۲ سال ثبت کنید
3. تمدید خودکار (اگر ممکن)
4. NS را به Cloudflare بدهید (یا DNS همان ثبت‌کننده)
5. رکوردها را بعداً بسازید (فصل 07)

## انواع رکورد (پیش‌نمایش)

| نوع | کاربرد |
|---|---|
| `A` | دامنه → IPv4 |
| `AAAA` | دامنه → IPv6 |
| `CNAME` | نام مستعار (`www`) |
| `TXT` | تأیید / SPF |
| `MX` | ایمیل |

## اشتباهات
- گذاشتن IP **داخلی** در DNS عمومی
- فراموش کردن `www`
- تست قبل از propagate شدن NS
