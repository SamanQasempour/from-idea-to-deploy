# از ایده تا دیپلوی

![از ایده تا دیپلوی](./assets/banner-from-idea-to-deploy-fa.png)

> راهنمای عملی و عمومی برای بردن یک اپ وب از ایده → گیت‌هاب → سرور → دامنه → کلودفلر → پروداکشن.
> وابسته به یک برند خاص نیست — برای هر اپ Node/Next روی VPS قابل استفاده است.

**زبان:** [English](./README.md) | فارسی

---


## چه یاد می‌گیرید

| مرحله | خروجی |
|---|---|
| ایده و دامنه | MVP مشخص + خرید/تنظیم دامنه |
| انتخاب هاست | Shared در برابر VPS در برابر مودم خانگی |
| گیت‌هاب | ریپو، توکن، SSH تا `git pull` دیگر پسورد نخواهد |
| لوکال و VM | اجرای لوکال، بعد روی لینوکس |
| شبکه | پورت‌فوروارد مودم + DNS/SSL کلودفلر |
| چندسایت | ریورس‌پراکسی وقتی چند سایت یک IP بیرونی دارند |
| انتشار | دیپلوی با systemd، امنیت، بکاپ، عیب‌یابی |

## چطور بخوانید

1. فصل‌ها را به ترتیب باز کنید (بالا و پایین هر صفحه **قبلی / بعدی** دارد).
2. دستورها را کپی کنید — جای `example.com` و `YOUR_IP` را عوض کنید.
3. روی سرور برای گیت‌هاب ترجیحاً **SSH key** بگذارید (فصل 03b).
4. رمز و توکن واقعی را commit نکنید.

## Placeholderهای نمونه

| Placeholder | معنی |
|---|---|
| `example.com` | دامنه شما |
| `USER` | یوزر لینوکس روی VM |
| `PUBLIC_IP` | آی‌پی عمومی اینترنت |
| `192.168.100.10` | آی‌پی داخلی VM |
| `/var/www/app` | مسیر اپ روی سرور |
