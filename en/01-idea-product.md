# 01 — Idea & product definition

## Goal
Turn a vague idea into a shippable MVP.

## Write this once (template)

```md
## Product one-liner
We help ___ do ___ so that ___.

## Users / roles
1. ...
2. ...

## Must-have for v1
- [ ] ...
- [ ] ...

## Explicitly NOT in v1
- ...
```

## Rules of a good MVP
- One core workflow end-to-end
- Real empty / loading / error states
- Prefer boring tech you can deploy

## Domain naming tip
Pick a name you can register today. Brand can evolve; DNS pain is forever if you rush.
